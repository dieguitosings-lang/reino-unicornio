# Reino Unicornio

Matemáticas para 2° de básica, con unicornios. Cada día hay 3 misiones cortas de 8 preguntas:

- Reconocer números: escuchar y encontrar el número, leer su nombre, contar bloques de base 10 y bolitas del ábaco, armar decenas y unidades, y familias de números.
- Secuencias: completar series, antes, entre y después, ordenar y comparar con > < =.
- Sumas y restas: con la recta numérica, sumas de dos cifras con y sin llevar, y problemas con historias.

Las preguntas se leen en voz alta. Si la respuesta está mal, aparece una pista. Cada juego sube o baja de nivel solo (números hasta el 20, hasta el 50 o hasta el 99).

Con las estrellas el unicornio gana premios: crin arcoíris, alas, corona y más.

Todo está en un solo archivo (`index.html`) y no necesita servidor. El progreso se guarda en cada dispositivo. Para pasarlo a otro dispositivo, usa el respaldo del panel de papás.
